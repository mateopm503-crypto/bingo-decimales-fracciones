# Bingo de Decimales y Fracciones · 6° Básico

Juego de bingo para la clase de matemática (operatoria con decimales y fracciones).

- **Bombo animado**: se saca una bolita (1 a 30) y aparece un problema tipo "Juanito tenía…". Los niños lo resuelven y buscan el resultado en su cartón.
- **45 cartones de 3×3** listos para imprimir (6 por hoja carta). Columna roja: sumas y restas con decimales · azul: multiplicación y división con decimales · verde: fracciones y números mixtos.
- **Revisar cartón**: escribe el número del cartón y te dice si tiene línea o bingo.
- **Solucionario** con el desarrollo de cada problema.

Abrir `index.html` en el navegador (no necesita instalar nada).
